# Day 1：你的第一个"会思考"的程序

## 今天学什么

Agent 最核心的骨架只有三步：**感知 → 思考 → 行动**。

今天我们用最简单的方式把这个骨架做出来：

1. 用户输入问题（感知）
2. AI 判断要不要查天气（思考），并用 JSON 告诉程序（关键！）
3. 程序根据 JSON 执行对应动作（行动）

## 今天的成果

一个能根据用户输入，自动判断"要不要查天气"的 Agent。

```
你：北京今天天气怎么样？
[AI 决策]: {"action": "get_weather", "city": "北京"}
Agent：北京的天气：晴，15°C，东风3级

你：1+1等于多少？
[AI 决策]: {"action": "answer", "content": "1+1等于2。"}
Agent：1+1等于2。
```

| `main.py` | 主程序入口，输入输出循环 |

## 今天最重要的一个概念

**让 AI 返回 JSON，而不是自然语言。**

AI 默认会说"好的，让我帮你查一下天气……"，这种文字程序没法处理。

通过 System Prompt 约束它，让它只返回 `{"action": "get_weather", "city": "北京"}` 这样的结构，程序才能理解并执行。

这就是 Agent 能"执行动作"的根本原因。

## 常见问题

**Q：AI 返回的不是纯 JSON，带了多余的文字怎么办？**

A：`actions.py` 里的 `safe_parse_json()` 会自动提取 JSON 块，不用担心。
如果还是出问题，把 `print(f"[AI 决策]: {response}")` 这行的输出截图，看看 AI 到底返回了什么。

**Q：天气数据是假的？**

A：是的，今天用的是 mock 数据。Day 2 会接入真实搜索 API。
