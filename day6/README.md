# Day 6：加入规划能力

## 今天学什么

面对复杂任务，好的做法是**先想清楚再动手**。

今天新增两个模块：
- `planner.py`：生成执行计划（3-6步，每步标明用哪个工具）
- `executor.py`：按照计划一步步执行，最后整合成完整答案

这就是 Plan-and-Execute 模式，比直接 ReAct 更适合处理有明确步骤的任务。

## 两种模式的区别

| 模式 | 用法 | 适合场景 |
|------|------|----------|
| 直接输入 | ReAct 循环 | 对话式问答，工具调用 1-3 次 |
| `/plan <任务>` | 先规划后执行 | 有明确步骤的研究/报告类任务 |

## 新增文件

| 文件 | 作用 |
|------|------|
| `planner.py` | 把任务分解成步骤列表 |
| `executor.py` | 按步骤执行并汇总结果 |
