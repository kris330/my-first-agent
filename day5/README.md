# Day 5：Agent Loop——让 Agent 多步完成任务

## 今天学什么

今天是整个课程里最关键的一天。

前4天，Agent 最多用一个工具，然后回答你。

从今天开始，Agent 能**反复思考、反复用工具**，直到任务完成。这就是 **ReAct 模式**：

```
Thought（思考）→ Action（行动）→ Observation（观察结果）→ Thought → ...
```

这是 GPT Agent、AutoGPT、BabyAGI 等所有 Agent 系统的核心循环。

```
1. ...
```

## ReAct 的本质

每次循环，AI 面对三个选择：

1. **用工具** (`tool_call`) — 还需要更多信息
2. **给答案** (`final_answer`) — 信息够了，任务完成
3. **问用户** (`ask_user`) — 需要人类补充信息

程序跟着 AI 的决定走，一步一步直到收到 `final_answer` 为止。

## 为什么要有 max_steps 上限

没有上限的话，如果 AI 陷入"总是觉得信息不够"的循环，会一直调用工具，账单飞起来。

`max_steps=5` 是一个合理的默认值。复杂任务可以改大，简单任务改小。
